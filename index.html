DEM to Terrain Mesh

Convert GeoTIFF elevation tiles into a terrain mesh for Rhino. Files stay in your browser and are not uploaded.

Where to get DEM tiles (GeoTIFF)
  • USGS National Map Downloader: United States. Choose Elevation Products (3DEP), then 1 meter DEM.
  • Discover GIS Data NY: New York State. In DEM Results, open the Null tab for the 1 Meter DEM Index (NYS).
  • ArcGIS Map Viewer: browse elevation layers and export DEM tiles for your area.
  • NOAA Data Access Viewer: coastal and lidar-derived DEMs, with custom area downloads.
  • OpenTopography: high-resolution lidar DEMs and global datasets. Global data often comes in latitude/longitude; reproject to UTM in QGIS before loading.

1. Load DEM tiles

One or more adjacent GeoTIFF tiles (.tif) in a projected coordinate system such as UTM. Adjacent tiles merge automatically.

2. Select the area

Drag a box on the shaded map. Without a box, the tool uses the full extent.

Importing into Rhino
  • Unzip, then Import or drag the .obj into Rhino.
  • In the OBJ import options, leave Map OBJ Y to Rhino Z unchecked. The file is already Z-up.
  • Set the Rhino model units to the output units you chose here.
  • The .txt file records the origin in map coordinates, so you can place other data (camera positions, survey points) in the same frame.
  • A DEM shows bare ground only. Trees and buildings are removed, and water surfaces are flattened.
